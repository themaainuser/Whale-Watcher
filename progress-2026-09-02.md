## 2. New bug found and fixed today: outbox drain would re-send forever

The new dry-run smoke no longer exercises the **DB write path**, so a live check was run against whale-pg (real insert → outbox → dedup → sent-marking → cleanup). It failed 1 of 4 checks — and the culprit was a bug from the 08-26 session itself:

- `pendingAlerts()` aliased the column in SQL (`transfer_id AS "transferId"`) but read `row.transfer_id` back → `Number(undefined)` = `NaN`.
- TypeScript's row-type generics can't catch an alias/key mismatch, so typecheck was green all along.
- **Production impact:** the outbox drain would have re-sent the same alert every 60 s forever — `markAlertSent(NaN)` updates nothing.
- **Fix** (`src/db.ts`): read `row.transferId`, with a comment explaining the alias/key agreement trap. Re-ran the live test: **4/4 passed**. Test rows cleaned up after (verified: 0 leftover).
